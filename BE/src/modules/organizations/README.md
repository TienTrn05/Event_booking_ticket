# organizations

Organization applications, own application reads/resubmission and Admin approve/reject are implemented in organization.routes.ts, application/, http/ and repositories/. Personal Google/email identity with ORGANIZER onboarding; pending membership allows drafts, active approved organization required for operations. Membership invitation/removal and public profile management APIs are not implemented.

See [outdoor implementation and limits](../../../../Docs/42-outdoor-zone-ticketing.md).
